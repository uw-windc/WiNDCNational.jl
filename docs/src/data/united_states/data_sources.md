
# [Data Sources](@id data_sources)

We only use one data source for the WiNDC National module, the Bureau of Economic Analysis (BEA) input/output tables using the Supply/Use framework. This includes both the summary and detailed tables. 


## Bureau of Economic Analysis - Summary Input/Output Tables

Download the `SUPPLY-USE` data from the BEA website:
